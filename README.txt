# Vinothèque op iPhone

Deze versie is een Progressive Web App (PWA). Om hem op iPhone als echte app te installeren,
moet hij één keer via een HTTPS-webadres worden geopend. Een los HTML-bestand uit de Bestanden-app
kan op iPhone beperkt werken en is daarom niet geschikt als definitieve versie.

## Snelste installatie met GitHub Pages
1. Maak op github.com een gratis account aan.
2. Maak een nieuwe repository, bijvoorbeeld `vinotheque`.
3. Upload ALLE bestanden uit deze map:
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon.svg
4. Zet in GitHub bij Settings → Pages de publicatie aan vanaf de `main` branch.
5. Open het verkregen HTTPS-adres in Safari op je iPhone.
6. Tik op Deel → Zet op beginscherm.
7. Open daarna Vinothèque vanaf je beginscherm.

De degustaties worden lokaal op het toestel opgeslagen. Gebruik de back-upfunctie in de app
wanneer we die verder uitbreiden om je gegevens veilig te bewaren.
